# Cybersecurity Portfolio

This repository documents my development journey in cybersecurity.

## Projects

- [siem-home-lab](siem-home-lab/README.md) — Home SOC lab: Splunk SIEM detection engineering. Splunk Enterprise collecting logs from Windows and Linux endpoints, attack simulations from Kali Linux and Atomic Red Team, and SPL detection rules mapped to MITRE ATT&CK. 2 attack scenarios documented, 2 detection rules written.

- [ctfs](ctfs/README.md) — Sanitized CTF write-ups (TryHackMe, with HackTheBox and picoCTF to come). Each focuses on the concepts, the method, and — where it applies — how a SOC would detect the attack. No flags, credentials, or step-by-step solutions, per each platform's Terms of Service. 4 rooms documented: Blue, Corridor, Hydra, RootMe.
